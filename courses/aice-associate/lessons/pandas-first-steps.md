## 오늘의 목표 (25분)

작은 표 데이터를 `DataFrame`으로 만들고, 열 선택·조건 필터·그룹별 평균을 직접 수행한다. 끝나면 [pandas 기초 실습 노트북](../notebooks/pandas-basics.ipynb)을 실행한다.

## 1. 핵심 개념

`DataFrame`은 행과 열로 된 표다. 각 열은 하나의 변수이며, `df["열이름"]`으로 선택한다. 조건식 `df["점수"] >= 70`은 각 행의 참·거짓을 만들고, `df[조건식]`은 참인 행만 남긴다. `groupby("그룹")["값"].mean()`은 그룹별 평균을 계산한다.

```python
import pandas as pd

df = pd.DataFrame({"팀": ["A", "A", "B"], "점수": [80, 60, 90]})
합격 = df[df["점수"] >= 70]
팀별평균 = df.groupby("팀")["점수"].mean()
```

## 2. 읽는 순서

1. `df.head()`로 행과 열이 예상대로인지 본다.
2. `df.shape`, `df.dtypes`로 크기와 자료형을 확인한다.
3. 결측치가 있는지 `df.isna().sum()`으로 센다.
4. 필터와 집계 결과의 행 수·단위를 설명한다.

숫자 평균을 계산하기 전에 문자열 숫자나 결측치가 섞이지 않았는지 확인해야 한다. 분석 결과는 숫자만 쓰지 말고 “A팀 평균은 70점”처럼 대상과 단위를 함께 적는다.
