# Associate 시험 직전 체크리스트

공식 안내 기준 Associate는 14문항, 90분, 80점 이상이며 Python 실기와 제한적 오픈북이다. 데이터 분석·전처리·AI 모델링을 모두 수행하므로 코드 탐색보다 입력과 평가 기준을 먼저 확인한다.

시험 전에는 브라우저·노트북·키보드와 허용 자료를 점검하고, `read_csv`, `train_test_split`, `ColumnTransformer`, 평가 지표 패턴을 직접 실행해 본다. 제출 전에는 누수 여부, 결측 처리, metric 선택, 그래프 축과 단위를 확인한다.
