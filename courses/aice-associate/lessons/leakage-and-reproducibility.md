# 누수 방지와 재현성

목표 이후에 알 수 있는 변수, 테스트 통계로 fit한 변환, 미래 기간의 행을 학습에 섞는 것은 누수다. `random_state`, 입력 파일 해시, 전처리 파라미터, 평가 분할을 기록하고 Pipeline과 고정된 split으로 재실행한다.

## 먼저 이해할 이론

누수는 모델이 운영 시점에 갖지 못할 정답 정보를 학습 또는 평가에서 미리 보는 문제다. 전처리도 학습의 일부이므로 평균·스케일·범주 목록을 train에만 fit하고 test에는 transform만 적용한다. 시계열 문제에서는 무작위 분할 자체가 미래를 과거에 섞을 수 있어 시간 순서를 보존한다.

예를 들어 대출 승인 후에 기록되는 `상환_연체일수`로 승인 여부를 예측하면 점수는 높아져도 배포 순간 사용할 수 없다. 반면 승인 전에 알 수 있는 소득 구간은 업무 정의와 시점을 확인한 뒤 사용할 수 있다.

## 목표·시험 포인트
예측 시점에 알 수 없는 열과 테스트 통계 사용을 누수로 판별한다.
```python
X_train, X_test = train_test_split(X, test_size=.2, random_state=42)
```
결과를 높이려고 전체 데이터로 전처리하거나 seed를 생략하지 않는다. 입력 해시·seed·split을 기록하고 동일 결과를 재실행한다.

흔한 오해는 누수가 모델 코드에만 있다는 것이다. 라벨 생성 이후의 집계표, 중복 고객이 train과 test에 함께 있는 상황, 사람이 test 결과를 보고 반복해 설정을 바꾸는 것도 평가를 낙관적으로 만든다. 스스로 설명할 때는 “예측 시점에 이 정보가 존재했는가?”를 먼저 묻는다.
