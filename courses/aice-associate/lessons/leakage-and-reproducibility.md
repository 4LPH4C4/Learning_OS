# 누수 방지와 재현성

목표 이후에 알 수 있는 변수, 테스트 통계로 fit한 변환, 미래 기간의 행을 학습에 섞는 것은 누수다. `random_state`, 입력 파일 해시, 전처리 파라미터, 평가 분할을 기록하고 Pipeline과 고정된 split으로 재실행한다.

## 목표·시험 포인트
예측 시점에 알 수 없는 열과 테스트 통계 사용을 누수로 판별한다.
```python
X_train, X_test = train_test_split(X, test_size=.2, random_state=42)
```
결과를 높이려고 전체 데이터로 전처리하거나 seed를 생략하지 않는다. 입력 해시·seed·split을 기록하고 동일 결과를 재실행한다.

완료 체크: [ ] 미래 변수 제거 [ ] 파라미터 기록 [ ] 재실행 확인.
