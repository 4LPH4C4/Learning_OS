# 결측치와 이상치 처리

결측 원인과 그룹별 분포를 확인한 후 제거·대표값 대체·별도 범주 중 방법을 고른다. 이상치는 IQR이나 도메인 범위로 후보를 찾되 원천 기록을 검증하고 유효한 희귀 사례를 임의 삭제하지 않는다. 처리 전후 행 수와 통계를 저장한다.

## 먼저 이해할 이론

결측은 단순한 빈칸이 아니라 데이터가 관측되지 않은 사건이다. 구매하지 않은 고객의 구매액이 비어 있는 것과 입력 오류로 비어 있는 것은 의미가 다르다. 중앙값 대체는 분포를 단순화하고, 행 삭제는 표본을 바꾼다. 따라서 대체 방법은 결측률뿐 아니라 결측 원인과 예측 시점의 정보로 결정한다.

IQR 밖의 값은 이상치 후보일 뿐 오류 판정이 아니다. 고가 고객이나 장애 직후의 큰 지연처럼 유효한 극단값일 수 있다. 도메인 범위, 원천 로그, 그룹별 비교를 통해 확인한다.

## 목표·시험 포인트
결측 메커니즘과 이상치의 업무 의미를 구분한다. IQR 경계와 그룹별 처리, 유효한 극단값 보존을 판단한다.
```python
q1, q3 = df["spend"].quantile([.25, .75]); iqr = q3-q1
outlier = ~df["spend"].between(q1-1.5*iqr, q3+1.5*iqr)
df["spend"] = df["spend"].fillna(df["spend"].median())
```
모든 결측을 0으로 바꾸거나 이상치를 자동 삭제하지 않는다. 처리 전후 분포·행 수와 근거를 제출한다.

스스로 설명하기: “이 값이 이상치라는 통계적 신호와 실제 오류라는 업무 판단은 어떻게 다른가?”에 답하고, 처리하지 않고 보존할 경우의 영향도 한 줄로 기록한다.
