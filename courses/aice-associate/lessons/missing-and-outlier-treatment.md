# 결측치와 이상치 처리

결측 원인과 그룹별 분포를 확인한 후 제거·대표값 대체·별도 범주 중 방법을 고른다. 이상치는 IQR이나 도메인 범위로 후보를 찾되 원천 기록을 검증하고 유효한 희귀 사례를 임의 삭제하지 않는다. 처리 전후 행 수와 통계를 저장한다.

## 목표·시험 포인트
결측 메커니즘과 이상치의 업무 의미를 구분한다. IQR 경계와 그룹별 처리, 유효한 극단값 보존을 판단한다.
```python
q1, q3 = df["spend"].quantile([.25, .75]); iqr = q3-q1
outlier = ~df["spend"].between(q1-1.5*iqr, q3+1.5*iqr)
df["spend"] = df["spend"].fillna(df["spend"].median())
```
모든 결측을 0으로 바꾸거나 이상치를 자동 삭제하지 않는다. 처리 전후 분포·행 수와 근거를 제출한다.
