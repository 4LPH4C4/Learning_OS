# 데이터 구성과 품질 점검

행은 관측 단위, 열은 변수라는 가정을 먼저 확인한다. 중복 키, 잘못된 타입, 허용 범위를 벗어난 값, 결측 비율을 표로 기록한다. 날짜는 날짜 타입으로 변환하고, 품질 문제는 원천 오류인지 업무상 의미인지 구분한다.

## 목표·시험 포인트
키 유일성·범위·타입·결측률을 점검하고 영향을 판단한다. 시험에서는 무조건 삭제하지 않고 조치 근거를 제시한다.
```python
quality = df.isna().mean().sort_values(ascending=False)
duplicate_count = df.duplicated(subset=["customer_id"]).sum()
invalid_age = (~df["age"].between(0, 110)).sum()
```
흔한 실수는 결측률 0을 품질 보증으로 착각하는 것이다. 오류 규칙 3개와 허용 기준을 만들고 원본을 보존한다.
