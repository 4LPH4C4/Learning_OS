# 데이터 정제 체크리스트

## 목적

분석 전에 오류를 찾아 결과를 재현 가능하게 만든다.

1. 열 이름의 공백과 표기 차이를 통일한다.
2. `isna().sum()`으로 결측치 개수를 확인하고, 삭제·대체·유지 이유를 기록한다.
3. `duplicated().sum()`으로 중복 행을 점검한다.
4. 날짜와 숫자 열의 자료형을 확인한다.
5. 극단값은 즉시 삭제하지 말고 입력 오류인지 실제 관측인지 확인한다.

## 짧은 실습

`df["이름"] = df["이름"].str.strip()`처럼 문자열 앞뒤 공백을 정리한 뒤, 정제 전후 행 수와 결측치 수를 비교한다. 정제 규칙과 변경된 행 수를 노트에 남기면 결과를 다시 검증할 수 있다.
