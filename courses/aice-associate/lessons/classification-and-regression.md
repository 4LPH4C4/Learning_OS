# 분류와 회귀 모델링

분류는 클래스, 회귀는 연속값을 예측한다. 기준선과 트리·랜덤포레스트·KNN 또는 선형 모델을 비교하고, 불균형이면 stratify와 클래스별 지표를 사용한다. 모델 선택은 점수 하나가 아니라 오류 비용과 운영 목적을 따른다.

## 먼저 이해할 이론

분류의 출력은 “어느 범주인가”이고 회귀의 출력은 “얼마나 큰 값인가”다. 분류 확률의 임계값을 바꾸면 정밀도와 재현율의 균형이 달라질 수 있지만, 회귀의 평균 오차와 같은 의미는 아니다. 기준선은 가장 단순한 규칙이 어느 정도인지 알려 주므로 복잡한 모델이 실제로 추가 가치를 주는지 판단하게 한다.

예를 들어 불량품을 놓치는 비용이 출하를 일시 중단하는 비용보다 크다면 accuracy가 높은 모델보다 재현율을 우선하는 임계값이 더 적합할 수 있다. 반대로 상담 인력을 낭비하는 오탐 비용이 크면 정밀도를 함께 봐야 한다.

## 목표·시험 포인트
문제 유형과 오류 비용에 맞춰 모델·metric을 선택한다. 불균형이면 accuracy만 보지 않는다.
```python
from sklearn.ensemble import RandomForestClassifier
model = RandomForestClassifier(n_estimators=100, random_state=42, class_weight="balanced")
```
흔한 실수는 회귀에 accuracy를 쓰거나 기준선 없이 복잡도를 높이는 것이다. 동일 split에서 baseline과 후보 모델을 비교한다.

흔한 오해는 “점수가 가장 높은 모델이 항상 최선”이라는 것이다. 동일한 분할, 동일한 전처리, 운영상 오류 비용, 추론 비용을 함께 비교해야 한다. 스스로 설명할 때는 문제 유형, 기준선, 선택한 지표, 지표가 반영하는 오류를 차례로 말한다.
