# 학업·업무 문제를 설명하고 해결하기

## 학습 목표

- 문제, 원인, 영향, 대안을 연결해 설명한다.
- 요청과 거절의 강도를 관계에 맞게 조절한다.
- 이메일·회의 메모에서 결정 사항과 담당자를 분리한다.

## 문제 설명의 네 칸

업무와 학업에서 어휘가 부족해도 구조가 분명하면 소통할 수 있다.

1. 현상: `最近系统经常变慢。`
2. 증거·영향: `下午三点以后，上传文件需要十分钟。`
3. 추정 원인: `可能跟同时使用的人太多有关。`
4. 다음 행동: `建议先检查服务器，再决定是否升级。`

사실과 추정을 구분하려면 `根据…`, `可能`, `看来`, `需要确认` 같은 표현을 쓴다. 확실하지 않은 원인을 단정하면 실무 중국어의 정확성이 떨어진다.

## 요청을 조절하기

`请发给我`는 직접적이고 분명하다. 부담을 낮추려면 `方便的话，请…`, `能不能麻烦您…`, `请问您什么时候可以…`를 쓴다. 거절할 때는 결론을 흐리지 않되 이유와 대안을 제시한다.

> 很抱歉，我今天无法完成全部内容。为了保证质量，我可以先提交第一部分，剩下的明天下午发给您。

사과만 하고 행동을 말하지 않거나, 가능하지 않은데 `可能吧`로 애매하게 답하지 않는다.

## 회의 기록 읽기

회의 메모는 발언자 수보다 결과가 중요하다. `决定`, `同意`, `负责`, `截止`, `待确认`을 찾아 결정·담당자·기한·미결 사항 표로 옮긴다. 의견 제시를 최종 결정으로 오해하지 않는다.

## 수행 연습

1. 최근의 작은 문제를 네 칸 구조로 120자 내외로 쓴다.
2. 상사, 동료, 친구에게 같은 부탁을 서로 다른 표현으로 한다.
3. 5분 회의 음성 또는 자막을 보고 결정·담당·기한을 정리한다.
4. 요청을 거절하되 대안과 확인 질문을 포함한 이메일을 쓴다.

## 시험 포인트

상황형 독해에서는 말투가 공손하다는 이유만으로 좋은 답은 아니다. 상대 질문에 답했는지, 실행 가능한 행동과 시간이 있는지 확인한다. 접속어 뒤의 결론과 `但是`, `不过` 뒤의 실제 입장을 놓치지 않는다.

## 통과 기준

익숙하지 않은 업무 문제를 90초 동안 원인과 대안까지 설명하고, 150자 이메일로 같은 내용을 정확히 전달한다.
