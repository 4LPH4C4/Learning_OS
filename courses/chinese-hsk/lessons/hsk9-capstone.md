# HSK 9 캡스톤 — 조사·발표·논증

## 프로젝트 목표

HSK 9의 학습을 문제 풀이 점수로 끝내지 않고, 중국어로 실제 문제를 조사하고 판단을 제안하는 결과물로 만든다. 하나의 주제를 정해 중국어 자료를 수집하고, 출처를 평가하고, 서면 보고서와 구두 발표를 완성한다.

## 산출물

- 1,200~1,800자 중국어 보고서
- 주장·근거·반론·제한을 포함한 7분 발표 녹음
- 3분 즉답을 가정한 예상 질문 5개와 답변
- 출처 표: 작성자·기관, 날짜, 자료 유형, 핵심 주장, 신뢰 한계
- 수정 기록: 초안에서 고친 표현 10개와 이유

## 1단계: 질문 좁히기

`인공지능은 좋은가`처럼 너무 큰 주제를 피한다. `대학의 생성형 AI 사용 지침이 초급 학습자의 피드백 속도와 독립적 글쓰기에 어떤 상충을 만드는가`처럼 대상, 맥락, 판단 기준을 포함한다. 답을 이미 정한 질문보다 반대 증거가 나올 수 있는 질문이 좋다.

## 2단계: 자료 삼각검증

기관 보고서, 학술·전문 자료, 현장 사례처럼 성격이 다른 중국어 출처 세 개 이상을 사용한다. 검색 결과 요약만 인용하지 않고 원문에서 범위와 발표 시점을 확인한다. 서로 같은 숫자를 인용해도 최초 출처가 하나라면 독립된 증거 세 개가 아니다.

각 자료의 이해관계와 방법을 기록한다. 내 결론에 불리한 자료도 적어도 하나 포함하고, 제외했다면 이유를 밝힌다.

## 3단계: 논증 설계

한 문장 결론을 먼저 쓴다. 근거마다 `이 사실이 왜 결론을 지지하는가`라는 연결 문장을 둔다. 가장 강한 반론을 상대가 인정할 정도로 공정하게 제시하고, 완전히 무효화하기보다 적용 조건이나 완화책으로 답한다.

보고서 구조 예:

1. 문제와 판단 기준
2. 자료와 조사 범위
3. 핵심 발견 두세 개
4. 대안 비교
5. 권고와 실행 조건
6. 제한과 추가 확인 과제

## 4단계: 언어와 전달 검수

유의어 선택, 결합 관계, 지시어의 선행사, 숫자 단위, 문체 일관성을 검사한다. 번역기를 사용했다면 원문과 역대조하고 자신이 설명하지 못하는 문장을 그대로 두지 않는다. 발표에서는 글을 읽지 말고 핵심어 카드로 말한다. 예상 밖 질문에는 아는 사실, 추정, 모르는 부분을 구분해 답한다.

## 평가 기준

| 영역 | 질문 |
|---|---|
| 정확성 | 출처의 주체·범위·강도를 바꾸지 않았는가? |
| 논증 | 근거가 결론과 연결되고 반론을 공정하게 다뤘는가? |
| 언어 | 어휘 결합과 문법이 자연스럽고 레지스터가 일관적인가? |
| 수행 | 시간 안에 발표하고 즉답에서 의미를 명료하게 전달하는가? |
| 성찰 | 한계와 다음 검증 행동을 구체적으로 제시하는가? |

## 완료 기준

보고서와 발표를 중국어 사용자 한 명 또는 교사에게 보여 주고, 내용 이해를 막은 오류와 단순 스타일 제안을 분리해 수정한다. 이 수행평가는 자동 배치진단이 확인하지 못하는 말하기·장문 쓰기를 보완한다.
