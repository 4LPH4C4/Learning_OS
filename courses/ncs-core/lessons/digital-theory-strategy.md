# 데이터·도구·AI·정보보호 활용 전략

## 디지털능력의 네 축

1. 목적에 맞는 도구 선택과 기본 조작
2. 데이터의 수집·정리·해석과 품질 확인
3. 개인정보·접근권한·보안·저작권을 지키는 책임 있는 사용
4. AI 결과를 검증하고 인간이 최종 책임을 지는 활용

## 데이터 품질

정확성, 완전성, 일관성, 적시성, 유일성을 확인한다. 같은 고객이 두 번 집계되거나 기준일이 다른 표를 합치면 정교한 분석도 잘못된 결론을 낸다. 원본은 보존하고 정제 규칙과 변경 이력을 남긴다.

## 보안 기본 행동

- 링크보다 발신자와 실제 도메인을 확인한다.
- 업무별 최소 권한을 부여하고 퇴사·이동 시 회수한다.
- 민감정보를 승인되지 않은 개인 도구에 입력하지 않는다.
- 백업은 생성뿐 아니라 복구 시험까지 해야 한다.
- 사고가 의심되면 숨기거나 직접 삭제하지 말고 절차에 따라 즉시 보고한다.

## AI 활용

AI는 초안, 분류 후보, 요약, 아이디어 확장에 유용하다. 하지만 출처·수치·누락·편향을 검증해야 한다. 고객 개인정보나 비공개 자료는 승인된 환경과 정책 범위에서만 쓴다. 중요한 채용·안전·법률 판단은 설명 가능한 근거와 사람의 검토를 둔다.

## 스프레드시트 검산

수식의 범위, 절대/상대 참조, 필터로 숨겨진 행, 텍스트로 저장된 숫자, 중복 키를 확인한다. 결과 일부를 손으로 계산해 대조하고 변경 전 원본을 보존한다.

## 선택지 판별 규칙

편리함만 강조하고 검증·권한·보안을 생략한 선택지는 피한다. 모든 데이터를 모으기보다 목적에 필요한 최소 데이터를 정확하게 관리한다.
