# 업무 문서 독해·작성·경청 전략

## 핵심 개념

의사소통은 말을 잘하는 능력만이 아니다. 업무 목적에 맞게 문서와 말을 이해하고, 필요한 정보를 빠짐없이 전달하며, 상대의 반응을 확인하는 순환 과정이다.

### 읽기

- 제목보다 먼저 **요구 행동, 기한, 담당, 조건**을 표시한다.
- 주장과 근거, 사실과 의견, 원인과 결과를 분리한다.
- 표·각주·단위·기준 시점을 본문과 함께 읽는다.
- `가능하다`, `원칙적으로`, `승인 후` 같은 범위 제한 표현을 놓치지 않는다.

### 쓰기

업무 메시지는 `결론 → 필요한 행동 → 근거 → 기한/문의처` 순서가 읽기 쉽다. 긴 문장은 한 문장 한 주장으로 나누고, 대명사 대신 대상 이름을 쓴다. 숫자는 단위와 기준일을 붙인다.

### 듣기와 말하기

적극적 경청은 동의가 아니다. 상대의 핵심 요구를 자기 말로 확인하고, 불명확한 조건을 열린 질문으로 좁히는 행동이다. 보고할 때는 문제를 숨기지 말고 현재 영향, 이미 한 조치, 필요한 결정을 함께 제시한다.

## 선택지 판별 규칙

- 빠르지만 수신자·목적·기한이 빠진 전달은 탈락한다.
- 감정이나 사람을 평가하는 표현보다 관찰 가능한 사실을 고른다.
- 모호한 지시를 임의로 해석하기보다 조건을 확인한다.
- 회의록에는 모든 발언보다 **결정·담당·기한·미결 사항**이 우선이다.

## 60초 풀이 루틴

1. 마지막 질문에서 요구 산출물을 확인한다.
2. 지문의 `누가/무엇을/언제/왜`에 표시한다.
3. 선택지마다 누락·과장·근거 없는 추론을 지운다.
4. 둘이 남으면 목적과 수신자에게 더 적합한 표현을 고른다.

## 실무 훈련

최근 보낸 메일 하나를 결론 우선 구조로 다시 쓴다. 받는 사람이 30초 안에 해야 할 행동과 기한을 알 수 있는지 확인한다.
