# 10회 모의고사 풀이·오답·재응시 프로토콜

## 운영 원칙

각 회차는 50문항, 60분이다. 평균 72초를 쓸 수 있지만 모든 문항에 같은 시간을 쓰지 않는다. 모의고사는 점수 측정이 아니라 시간 배분과 판단 습관을 교정하는 실험이다.

## 1차 풀이

- 0~35분: 바로 풀 수 있는 독해·판단·짧은 계산을 해결한다.
- 35~50분: 표시한 도표·복합 계산·조건 추론을 푼다.
- 50~60분: 미응답을 없애고 단위·부정어·정답 수를 검토한다.

한 문항에서 90초가 지나도 식이나 판단 기준을 못 세웠다면 표시하고 이동한다.

## 오답 분류

| 코드 | 원인 | 다음 행동 |
|---|---|---|
| C | 개념 부족 | 해당 이론 Lesson을 다시 읽고 자기 예시를 만든다. |
| R | 조건 누락 | 질문·단위·제약에 표시하는 루틴을 반복한다. |
| M | 계산 실수 | 식과 중간 단위를 적고 역산한다. |
| T | 시간 부족 | 1차 풀이에서 넘길 문항 기준을 조정한다. |
| J | 판단 오류 | 선택지별 탈락 근거를 한 문장으로 쓴다. |

## 회차 운영

- 1~2회: 현재 점수와 시간 병목 파악
- 3~5회: 약점 영역별 이론 복습과 풀이 루틴 고정
- 6~8회: 60분 실전 조건, 오답 재발률 감소
- 9~10회: 점수 변동 폭과 연속 합격 여부 확인

60점은 코스의 기본 목표일 뿐 기관별 실제 전형의 합격선이 아니다. 지원 기관의 시험 영역·문항 수·가점 기준은 반드시 해당 채용 공고로 다시 확인한다.

## 재응시 기준

정답을 외운 직후 같은 회차를 반복하지 않는다. 오답 원인을 교정한 뒤 최소 며칠 간격을 두고, 정답뿐 아니라 다른 선택지가 왜 틀렸는지 설명할 수 있는지 확인한다.
